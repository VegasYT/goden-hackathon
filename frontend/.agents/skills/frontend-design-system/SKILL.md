# Дизайн-система Goden

Источник решений для вёрстки во `frontend/`. Скиллы `interface-design` и `no-ai-design-slop` берут решения системы отсюда, а не из `.interface-design/system.md`: направление уже выбрано, его не пересматривают на каждом экране.

Проверка работы: витрина `/dev/ui` в `pnpm dev` (все токены и компоненты, тема переключается в навигации) и `pnpm check`.

## Цвет

Цвет сообщает смысл, а не украшает.

- **Нормальное состояние — без цвета.** Свежая партия, обычная строка, неактивный пункт.
- **Янтарный (`warning`) — внимание:** срок скоро истекает, нужно решение.
- **Красный (`error`) — опасность или запрет:** просрочено, стоп-лист, необратимое удаление.
- **Зелёный (`primary`/`success`) — только основное действие, активный пункт навигации и успех.** Одна контрастная кнопка `variant='contained'` на экран.
- **Статус всегда дублируется текстом или иконкой с подписью** — не только цветом.

Цвета берутся только из темы, hex в компонентах запрещён:

```tsx
<Typography sx={{ color: 'text.secondary' }} />
<Box sx={{ bgcolor: 'warning.tint', color: 'warning.onTint' }} />
// в функции стиля, когда нужна CSS-переменная (themeVars и fieldFocusRing из @shared/ui/theme):
sx={(theme) => ({ boxShadow: `0 0 0 1px ${themeVars(theme).palette.divider}` })}
```

`theme.palette.*` в стилях не используется: это цвета светлой темы, в тёмной они неверны. Только `themeVars(theme)` или ключ темы строкой.

| Ключ темы | Смысл |
|---|---|
| `background.default` / `background.paper` | фон страницы / карточки и панели |
| `text.strong` / `text.primary` / `text.secondary` / `text.tertiary` | заголовки и значения / основной / вторичный / метаданные |
| `divider`, `lineStrong`, `lineInput` | разделители и рамки / контур вторичных кнопок / граница полей (3:1) |
| `field`, `track` | фон полей / дорожки прогресса и фон сегментов |
| `primary.main`, `primary.ink`, `primary.tint`, `primary.onTint` | заливка кнопки / зелёный текст и иконки / подложка / текст на подложке |
| `warning.*`, `error.*` | то же устройство: `main` — графика, `ink` — текст, `tint`/`onTint` — плашки |
| `neutralFill`, `overlay` | нейтральная графика / затемнение под диалогом |

`text.tertiary` не ставится на фон `track`: там контраст ниже 4.5:1. Новый цвет добавляется в `tokens.ts` для обеих тем и, если это пара «текст на фоне», в `contrastPairs` — автотест не даст опуститься ниже WCAG AA.

## Типографика

- Шрифт Golos Text, насыщенности 400/500/600. **Моноширинный шрифт не используется нигде**, ровные колонки чисел дают табличные цифры (включены глобально).
- Варианты: `h1` — заголовок страницы (один на странице, его даёт `PageHeader`), `h2` — заголовок диалога или drawer, `h3` — секция, `body1`, `body2`, `caption`. Варианты `h4`–`h6`, `subtitle*`, `overline` запрещены типами.
- Цвет `h1`–`h3` (`text.strong`) задаёт тема в `MuiTypography`, `DialogTitle` по умолчанию `h2`: в `sx` их не повторяй.
- Без капса и надписей с разрядкой над секциями: иерархию дают насыщенность и цвет.
- Числа по-русски: десятичная запятая, «12,0 кг», «360 шт».

## Отступы, радиусы, глубина

- Отступы кратны 4px: `0.5` = 4px в `sx`. Используемые значения: 4, 8, 12, 16, 20, 24, 32.
- Радиусы: `theme.shape.radius` — `xs` 4 (чипы), `sm` 6 (кнопки, поля), `md` 8 (поля на планшете, навигация), `lg` 12 (карточки), `xl` 14 (диалоги). В `sx` — `borderRadius: radius(theme, 'md')` из `@shared/ui/theme`: число в `sx` умножается на `shape.borderRadius`. Карточка в потоке — `Paper`, он уже со скруглением `lg` и кольцом.
- Глубина одним способом: в потоке страницы — тонкая рамка (`Paper` по умолчанию с `elevation: 0` и рамкой `divider`), тени только у всплывающих слоёв (меню, диалог, drawer). Не добавляй тени карточкам.

## Плотность

- Размер элементов — по способу ввода: `@media (pointer: coarse)` (константа `coarsePointer`). На планшете цели касания не меньше 44×44, основная кнопка 48px; на ноутбуке поля и кнопки 32–40px.
- Раскладка — по ширине: от 1200px (`lg`) боковая панель, уже — рельс.
- Компоненты MUI уже настроены в `components.ts` (кнопки и `IconButton` на планшете — от 44 px, чипы — `small`): не повторяй это в `sx`. Своему компоненту с интерактивом (`ButtonBase`) добавляй `[coarsePointer]: { minHeight: 44 }`.

## Иконки

- Только Material Symbols Rounded через `<Icon name='…' />` из `@shared/ui/icon`. Прямые импорты SVG в компонентах запрещены.
- Новая иконка — одна запись в `icons.ts`; `filled` — только для активного состояния (навигация).
- Значки плашек (`Alert`), стрелку `Select` и значки `Autocomplete` тема берёт из нашего набора; `iconMapping` в компонентах не задаётся.
- Иконки разделов навигации собраны из контуров тех же Material Symbols, разбитых на части (`nav-icons.gen.tsx`, генератор `scripts/gen-nav-icons.mjs`, команда `pnpm icons:nav`). Части двигаются при наведении на пункт навигации: стили `navIconMotion` из `@shared/ui/icon`, при системном уменьшении движения анимации нет. Новый раздел навигации — запись в генераторе, а не прямой импорт SVG.
- Без `label` иконка декоративная (`aria-hidden`), с `label` — озвучивается. Кнопке из одной иконки нужен `aria-label`.

## Компоненты `shared/ui`

| Компонент | Когда |
|---|---|
| `PageContent` | контейнер содержимого страницы со стандартными отступами; `ActionBar` передаётся слотом `actionBar` |
| `PageHeader` | шапка каждой страницы: путь, `h1`, статус, подробности, действия |
| `Breadcrumbs`, `BreadcrumbLink` | путь к странице в `PageHeader`: «Поставки › № 118» |
| `SectionTabs` (`@shared/ui/link`) | вкладки раздела из `TabLink` под шапкой, на планшете во всю ширину |
| `SegmentedControl` | выбор одного варианта из 2–4, например фильтр со счётчиками |
| `QuantityField` | ввод количества с −/+ и десятичной запятой, `unit` в подписи |
| `ActionBar` | итог и основное действие внизу экрана; передаётся в `actionBar` у `PageContent` |
| `ConfirmDialog` | любое критичное действие; `dismissibleNotice` скрывает только предупреждение (читается один раз при открытии) |
| `FormDialog` | форма в диалоге: Enter отправляет, `maxWidth`, `pending` у формы с запросом |
| `EmptyState` | пустой список или раздел: приглашение, а не извинение |
| `QueryState`, `LoadErrorState` | загрузка (заготовка `SkeletonList`), ошибка с «Повторить» и данные запроса; `LoadErrorState` принимает сам запрос (`query`) |
| `NoResultsState` | поиск или фильтры ничего не нашли: что искали и «Сбросить поиск» |
| `CardList`, `CardListItem` | список карточек на планшете: `Card` темы (радиус `lg`, кольцо), не рамка |
| `ListPagination`, `usePagedSearch` | пагинация списка из адреса; линия сверху только над карточками |
| `SortableHeaderCell` | заголовок колонки с сортировкой сервера и `aria-sort` |
| `TimelineItem` | событие ленты истории: круглый значок и содержимое |
| `RetryAlert` | неудачная запись: ошибка, пояснение и «Повторить» |
| `useLeaveConfirm` | вопрос «Уйти?» при уходе с несохранённой формы |
| `useNotice` | сообщение после записи: 6 с, с действием 8 с, щелчок мимо его не закрывает |
| `ReadOnlyNote`, `InfoNote` | пояснение «только чтение» с замком / спокойная подсказка с «i» |
| `ActionMenu` | кнопка «⋮» строки с меню действий, у каждого пункта значок |
| `DisclosureIcon` | значок раскрытия строки: «›» поворачивается в «⌄» |
| `EmptyValue` | прочерк «—» на месте пустого значения, `text.secondary` |
| `StandaloneScreen` | экран без оболочки: запуск, нет доступа, ошибка входа, страницы входа Keycloak |
| `ConnectionIndicator`, `ConnectionBanner` | состояние связи с сервером (данные — пропсом `ConnectionState`) |
| `Logo` | знак и название в оболочке; знак светлой и тёмной темы — `mark-light.svg` и `mark-dark.svg` рядом с компонентом |
| `Icon` | любая иконка |

Обычные элементы — компоненты MUI как есть (`Button`, `TextField`, `Chip`, `Table`, `Alert`, `Dialog`…): тема уже приводит их к системе.

- `Button`: `contained` — основное действие, `outlined` — вторичное, `text` — тихое; `color='error'` — необратимое.
- `TextField`: подпись всегда над полем.
- `Chip`: `default` — нейтральный статус (кольцо темы, без `variant='outlined'`), `warning`/`error`/`success` — статусы с подложкой.
- `Alert`: `warning`/`error`/`success` — на подложке статуса, `info` — спокойная плашка без статуса (фон поля, кольцо, серый значок).
- `Dialog`: заголовок `DialogTitle` без `variant` и `id` — `h2` и связь с окном дают тема и Dialog; отступы `DialogActions` тоже из темы.

## Как решать, куда писать стиль

1. Подходит компонент MUI или `shared/ui` как есть — используй его без стилей.
2. Разовая раскладка (отступы, flex, grid) — `sx` с токенами темы.
3. Повторяется во втором месте — выноси компонент в `shared/ui` (без бизнес-логики) или в слой своей фичи.
4. Нужно изменить вид компонента MUI везде — правь `components.ts`, а не точечные `sx`.

Страница кладёт содержимое в `PageContent`, а `ActionBar` передаёт в его слот `actionBar`: панель встаёт после блока с отступами.

## Тема

По умолчанию — тема системы пользователя, если она неизвестна — светлая. Явный выбор в `ModeToggle` сохраняется (`colorModeStorageKey`) и важнее системной темы. Скрипт `colorModeInitScript` применяет тему до загрузки приложения: плагин `theme-init` в `vite.config.ts` вставляет его в `<head>` (`script#theme-init`), `theme-init.test.ts` выполняет его напрямую. Тёмная тема — полноценная: проверяй новый экран в обеих.
