## MODIFIED Requirements

### Requirement: Различимые конфликты
Ответ 409 SHALL различать по полю `type`:
- `delivery-already-approved` — поставка уже принята;
- `delivery-not-approved` — поставка ещё не принята;
- `quarantine-closed` — у позиции нет открытого карантина;
- `version-conflict` — объект изменён одновременным запросом, запрос можно повторить;
- `product-in-use` — продукт есть в рецептурах неархивных блюд, `detail` называет их;
- `unit-locked` — единицу продукта уже нельзя менять;
- `archived-ingredients` — в рецептуре восстанавливаемого блюда есть архивные продукты, `detail` называет их.

Остальные конфликты SHALL иметь `type` `conflict`.

#### Scenario: Повторная приёмка
- **WHEN** принятую поставку принимают ещё раз
- **THEN** возвращается статус 409 с `type` `delivery-already-approved`

#### Scenario: Закрытый карантин
- **WHEN** решение отправляют по позиции, карантин которой уже решён
- **THEN** возвращается статус 409 с `type` `quarantine-closed`

#### Scenario: Занятое название
- **WHEN** создают продукт с уже занятым названием
- **THEN** возвращается статус 409 с `type` `conflict`

#### Scenario: Продукт в рецептуре
- **WHEN** в архив отправляют продукт из рецептуры блюда "Омлет"
- **THEN** возвращается статус 409 с `type` `product-in-use`, `detail` называет "Омлет"

## ADDED Requirements

### Requirement: Поле в ошибке названия и почты
Ошибка SHALL указывать поле запроса, к которому относится, чтобы форма показала её у поля:
- занятое название продукта, блюда, точки или компании — 409 с `errors` из одного элемента: поле `name` и `code`;
  - `taken` — название занято;
  - `taken_by_archived` — название занято архивным продуктом или блюдом;
- незарегистрированная почта при назначении сотрудника и передаче компании — 422 с элементом: поле `email`, `code` `unknown`.

Статусы и `type` прежних ответов SHALL NOT меняться.

#### Scenario: Занятое название точки
- **WHEN** создают точку с названием, которое уже есть в компании
- **THEN** возвращается статус 409, в `errors` поле `name` с `code` `taken`

#### Scenario: Название архивного продукта
- **WHEN** создают продукт с названием архивного продукта
- **THEN** возвращается статус 409, в `errors` поле `name` с `code` `taken_by_archived`

#### Scenario: Незарегистрированная почта сотрудника
- **WHEN** на точку добавляют сотрудника по почте, с которой никто не входил
- **THEN** возвращается статус 422, в `errors` поле `email` с `code` `unknown`
