## Why

В разделе «Аналитика» нет двух экранов с холста макетов: прогноза стоп-листа со шкалой времени и графика списаний по дням. Первый не требовал API, для второго API добавлен (`write-off-days`).

## What Changes

- Прогноз стоп-листа показывается шкалой: полоса до момента дефицита на шкале горизонта с делениями по дням, число порций, на которое хватит ограничивающего продукта, и количество продукта на порцию. На ноутбуке и на планшете - один вид строк.
- Новый блок «Списания по дням»: столбцы за каждый день периода, разделённые на "истёк срок" и "порча и другие причины"; по умолчанию - число операций, при выборе продукта - количество в его единице. Подсказка со значениями дня, дни без списаний - пустые столбцы. Выбранный продукт хранится в адресе.
- Зависимость `@mui/x-charts` для графика.

Вне изменения:
- выбор окна истории расхода прогноза;
- графики дефицита.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `frontend-analytics`: прогноз шкалой времени, списания по дням.

## Impact

- `frontend/`: `src/pages/analytics`, роут аналитики, `package.json` (`@mui/x-charts`), типы контракта (`pnpm api:types`), `frontend/AGENTS.md`, `frontend/CHECKLIST.md`.
- `backend/` в этом change не меняется: операция появилась в `write-off-days`.
