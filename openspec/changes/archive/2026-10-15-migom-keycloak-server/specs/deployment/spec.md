## ADDED Requirements

### Requirement: Клиенты Мигома на сервере
При каждой выкладке система SHALL заводить в Keycloak сервера клиентов сервиса доставки Мигом, которых там нет, с их ролями, не пересоздавая данные Keycloak. Секреты клиентов Мигома SHALL браться из настроек окружения при каждой выкладке. Если секрет не задан, клиент SHALL NOT принимать секрет из файла realm.

#### Scenario: Клиентов нет
- **WHEN** на сервере с зарегистрированными пользователями выкладывают версию с заданными секретами Мигома
- **THEN** сервисная учётная запись Мигома получает токен с ролью `migom.integration` по секрету из настроек, пользователи сохранились

#### Scenario: Секрет сменили
- **WHEN** секрет Мигома в настройках окружения меняют и выкладывают версию
- **THEN** токен выдаётся по новому секрету, по старому - нет

#### Scenario: Секрет не задан
- **WHEN** секрет Мигома не задан
- **THEN** токен по секрету разработки из файла realm не выдаётся
