# Spec Delta

## ADDED Requirements

### Requirement: Продукты в HTTP API
Система SHALL предоставлять через HTTP API создание продукта, чтение продукта по идентификатору и постраничное чтение списка продуктов по правилам возможности `http-api`. Создание SHALL возвращать статус 201 и созданный продукт. Список SHALL быть упорядочен по названию. Правила корректности продукта SHALL быть теми же, что и без HTTP. Нарушения, выразимые в контракте (неизвестная единица измерения, неположительный срок хранения, отсутствие обязательного поля), SHALL отклоняться со статусом 400. Пустое название или название из одних пробелов даёт статус 422 с указанием поля, занятое название - статус 409, отсутствующий продукт - статус 404.

#### Scenario: Создание продукта
- **WHEN** отправляют `POST /api/v1/products` с названием "Сливки 33%", единицей `ml`, категорией и сроком хранения 5 дней
- **THEN** возвращается статус 201 и продукт с идентификатором и теми же данными

#### Scenario: Чтение продукта
- **WHEN** отправляют `GET /api/v1/products/{id}` для созданного продукта
- **THEN** возвращается статус 200 и этот продукт

#### Scenario: Список продуктов
- **WHEN** созданы продукты "Яйцо", "Бекон", "Сливки 33%" и отправляют `GET /api/v1/products`
- **THEN** возвращается статус 200, три продукта в порядке "Бекон", "Сливки 33%", "Яйцо" и общее число 3

#### Scenario: Страница списка
- **WHEN** отправляют `GET /api/v1/products?limit=2&offset=2` при трёх продуктах
- **THEN** возвращается один продукт и общее число 3

#### Scenario: Занятое название
- **WHEN** отправляют `POST /api/v1/products` с названием существующего продукта
- **THEN** возвращается статус 409

#### Scenario: Неизвестная единица измерения
- **WHEN** отправляют `POST /api/v1/products` с единицей `kg`
- **THEN** запрос отклоняется как не соответствующий контракту со статусом 400
