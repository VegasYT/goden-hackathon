# Proposal

## Why

Grafana уже показывает метрики, но логи контейнеров доступны только через `docker compose logs`, поэтому диагностика API, worker и генератора требует доступа к серверу. ADR-007 и план проекта требуют централизованную доставку stdout-логов через Promtail в Loki и их просмотр в Grafana.

## What Changes

- Добавить в локальный и серверный Docker Compose сервисы Loki и Promtail с закреплёнными версиями и проверками готовности.
- Собирать stdout/stderr контейнеров проекта, помечать записи окружением и именем compose-сервиса и отправлять их в Loki без вынесения высококардинальных полей в labels.
- Разбирать структурированные JSON-логи backend при запросе, сохраняя возможность искать по `level`, `msg` и `correlation_id`; неструктурированные логи остальных сервисов оставлять доступными как текст.
- Зафиксировать уровни backend `DEBUG`, `INFO`, `WARN`, `ERROR`: `LOG_LEVEL` задаёт минимальный уровень для API, worker и generator, по умолчанию используется `INFO`.
- Provisioning Grafana дополнить источником Loki, чтобы логи были доступны в Explore без ручной настройки.
- На сервере сохранять данные Loki и позиции Promtail между обычными выкладками, ограничить срок хранения и не публиковать Loki или Promtail в интернет.
- Описать запуск, проверку, поиск по сервису и correlation ID и очистку данных логов.

Вне изменения: перевод приложений на другой формат логов; сбор логов backend-процессов, запущенных напрямую на хосте в локальной разработке; готовый логовый дашборд и алерты по логам; централизованный сбор с нескольких серверов; миграция с Promtail на Grafana Alloy.

## Capabilities

### New Capabilities

- `centralized-logs`: сбор контейнерных логов Promtail, хранение в Loki и поиск в Grafana.

### Modified Capabilities

- `backend-platform`: уточняется набор уровней структурированных логов, переменная минимального уровня и значение по умолчанию.
- `dev-environment`: локальный compose дополнительно поднимает Loki и Promtail и предоставляет настроенный просмотр контейнерных логов.
- `deployment`: серверный набор дополнительно запускает Loki и Promtail, сохраняет логовые данные и не публикует служебные интерфейсы наружу.

## Impact

- `infra/`: оба compose-файла, конфигурации Loki и Promtail, provisioning Grafana, тома и документация эксплуатации.
- Новые зависимости: образы Grafana Loki и Promtail. Promtail достиг EOL 2 марта 2026 года, поэтому образ должен быть закреплён; переход на поддерживаемый Grafana Alloy остаётся отдельным изменением.
- Код backend, frontend и публичный API не меняются: backend уже пишет JSON в stdout, поддерживает `LOG_LEVEL` и передаёт `correlation_id` в структурированные записи. Меняются compose-настройки и документация запуска backend-контейнеров.
