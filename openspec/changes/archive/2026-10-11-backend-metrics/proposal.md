# Proposal

## Why

О работе системы сейчас можно судить только по логам: нет ответа на вопросы "сколько заказов отклонено за час", "как быстро отвечает приёмка", "упирается ли API в пул соединений", "часто ли команды повторяются из-за конфликтов". ADR-007 требует технические и бизнес-метрики в Prometheus и дашборды в Grafana; для защиты проекта дашборд с живыми числами под генератором - наглядное подтверждение работы системы. Это задача A8 из [backend/plan.md](../../../backend/plan.md).

## What Changes

- Каждый процесс backend (`api`, `worker`, `generator`) отдаёт метрики в формате Prometheus на `/metrics` рядом с `/healthz`.
- Метрики API: число запросов и время ответа по операции контракта и статусу.
- Метрики команд: число выполненных команд по имени и исходу, повторы из-за конфликта версий, ответы из сохранённого результата по ключу идемпотентности.
- Бизнес-метрики стороны записи: принятые и отклонённые заказы, зарегистрированные и принятые поставки, объём списаний по причине.
- Состояние пула соединений PostgreSQL и стандартные метрики процесса Go.
- Метрики генератора: выполненные действия по виду и исходу.
- В окружение разработки добавляются Prometheus и Grafana с готовым источником данных и дашбордом; Prometheus опрашивает процессы backend на хосте.

Вне изменения:

- метрики стороны чтения - отставание проекций, истекающие и просроченные партии, задержка Kafka: появятся вместе с проекциями, publisher и контролем сроков (задачи B1, B4, B6);
- Loki и Promtail, правила оповещений Grafana;
- трассировка OpenTelemetry: интеграция ogen остаётся отключённой, запросы связывает correlation ID в логах.

## Capabilities

### New Capabilities

- `metrics`: метрики процессов backend - эндпоинт, состав, правила именования и меток, окружение для их просмотра.

### Modified Capabilities

- `dev-environment`: в окружение добавляются Prometheus и Grafana.

## Impact

- **Код:** `internal/platform/observability` (реестр, метрики HTTP и пула), `httpx` (эндпоинт `/metrics`, middleware), `command` (счётчики команд), `inventory`, `orders`, `generator` (бизнес-счётчики), `internal/api` и три `cmd/*` (подключение).
- **Зависимости:** `github.com/prometheus/client_golang` (есть в стеке `backend/AGENTS.md`).
- **Окружение:** `infra/compose.yaml`, новые `infra/prometheus/` и `infra/grafana/`.
- **Документы:** `backend/AGENTS.md` (правила метрик, адреса), `backend/plan.md` (статус A8).
- **Безопасность:** `/metrics` доступен без токена, как `/healthz`: он не под `/api/v1`. В метках нет идентификаторов пользователей и объектов.
- **Разработчик B:** получает готовый реестр и образец для метрик проекций и Kafka.
