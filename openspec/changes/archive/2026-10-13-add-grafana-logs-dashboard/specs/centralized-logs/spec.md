# Spec Delta

## ADDED Requirements

### Requirement: Логи на дашборде backend
Существующий provisioned-дашборд backend в Grafana SHALL без ручной настройки совмещать метрики с логовыми панелями: выбором окружения и compose-сервиса, общей лентой контейнерных записей, фильтрами структурированных записей и количеством ошибок по сервисам.

#### Scenario: Логовые панели созданы автоматически
- **WHEN** Grafana запускается с provisioned конфигурацией проекта
- **THEN** существующий дашборд backend сохраняет панели метрик и содержит логовые панели с источником Loki

#### Scenario: Выбор окружения и сервиса
- **WHEN** оператор выбирает окружение и один или все доступные сервисы
- **THEN** панели показывают только записи выбранного окружения и сервисов за период дашборда

#### Scenario: Общая лента
- **WHEN** выбранный сервис записал JSON или обычный текст
- **THEN** общая лента показывает исходную запись без требования к её формату

#### Scenario: Фильтр уровня
- **WHEN** оператор выбирает один или несколько уровней `DEBUG`, `INFO`, `WARN`, `ERROR`
- **THEN** лента структурированных логов показывает записи только выбранных уровней

#### Scenario: Поиск связанного запроса
- **WHEN** оператор задаёт `correlation_id`
- **THEN** лента структурированных логов показывает записи с этим идентификатором

#### Scenario: Ошибки по сервисам
- **WHEN** за выбранный период сервисы записали сообщения уровня `ERROR`
- **THEN** дашборд показывает количество таких сообщений отдельно для каждого сервиса

#### Scenario: Подходящих логов нет
- **WHEN** выбранные фильтры не находят записей
- **THEN** панели показывают пустой результат без ошибки источника данных
