## ADDED Requirements

### Requirement: Порядок событий при одновременной смене рецептуры
События одного блюда SHALL идти в общем порядке чтения событий по возрастанию версий потока, в том числе когда рецептуру одного блюда меняют одновременно несколькими запросами с ключами идемпотентности. Каталог, перестроенный из событий, SHALL совпадать с текущим.

#### Scenario: Одновременная смена рецептуры
- **WHEN** рецептуру одного блюда одновременно меняют несколькими запросами с разными ключами идемпотентности
- **THEN** все запросы выполнены, события блюда читаются в общем порядке по возрастанию версий, а перестроенная из событий рецептура совпадает с текущей
