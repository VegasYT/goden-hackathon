## ADDED Requirements

### Requirement: Завершение потоков при остановке API
При остановке процесса API открытые потоки SHALL закрываться сразу, не дожидаясь истечения срока остановки. Процесс с подключёнными клиентами SHALL завершаться штатно.

#### Scenario: Остановка с подключённым клиентом
- **WHEN** процесс API получает сигнал остановки, а к потоку подключён клиент
- **THEN** поток закрывается, процесс завершается без ошибки раньше срока остановки

### Requirement: Переподключение из браузера
Запрос на подключение к потоку с другого разрешённого источника SHALL приниматься и тогда, когда клиент передаёт заголовок `Last-Event-ID`.

#### Scenario: Предварительный запрос с Last-Event-ID
- **WHEN** браузер с разрешённого источника отправляет предварительный запрос CORS, перечисляя заголовки `Authorization` и `Last-Event-ID`
- **THEN** сервер разрешает оба заголовка

### Requirement: Срок на запись в поток
Запись события в поток SHALL иметь срок. Соединение с клиентом, который не читает поток, SHALL закрываться по истечении срока, а не удерживаться бесконечно.

#### Scenario: Клиент не читает
- **WHEN** клиент держит соединение, но не читает данные, а сервер пытается записать событие
- **THEN** запись прерывается по сроку, соединение закрыто
