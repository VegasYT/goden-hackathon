## ADDED Requirements

### Requirement: Страницы списка партий
Список партий продукта SHALL возвращаться страницами с параметрами `limit` и `offset` и общим числом партий, подходящих под условия запроса. Параметр `in_stock` SHALL ограничивать список партиями с остатком больше нуля; без него возвращаются все партии. Порядок партий SHALL оставаться прежним. Запрос партий продукта, которого нет в каталоге, SHALL отклоняться как "не найдено".

#### Scenario: Первая страница
- **WHEN** у продукта 120 партий и запрашивают список без параметров
- **THEN** возвращаются первые 50 партий по порядку и общее число 120

#### Scenario: Следующая страница
- **WHEN** запрашивают список с `limit=50` и `offset=100`
- **THEN** возвращаются оставшиеся 20 партий

#### Scenario: Только с остатком
- **WHEN** у продукта три партии, одна из них израсходована полностью, и запрашивают список с `in_stock=true`
- **THEN** возвращаются две партии с остатком, общее число равно двум

#### Scenario: Неизвестный продукт
- **WHEN** запрашивают партии продукта, которого нет в каталоге
- **THEN** ответ - "не найдено"
