## Why

Проверка backend (`backend/review.md`) нашла три находки средней важности в API и потоке обновлений:

- **находка 7**: одновременная смена рецептуры одного блюда может записать события потока так, что в общем порядке чтения более поздняя версия окажется раньше: перестроение каталога даст не ту рецептуру;
- **находка 8**: список партий продукта отдаёт все партии за всё время, включая пустые, без пагинации; у бекона за час работы генератора больше ста партий, ответ растёт без предела. Для неизвестного продукта ответ 200 с пустым списком, а движения в том же случае отвечают 404;
- **находка 25**: открытый поток SSE мешает завершению API при выкладке (ожидание 15 секунд и выход с ошибкой); переподключение из браузера с другого источника может быть отклонено из-за заголовка `Last-Event-ID`; клиент, который не читает, удерживает соединение без срока.

## What Changes

- **Смена рецептуры** берёт блокировку потока блюда: события одного блюда идут в общем порядке по версиям.
- **Список партий** (`GET /products/{productId}/batches`): пагинация `limit` и `offset` с общим числом в ответе, необязательный параметр `in_stock` (только партии с остатком), 404 для неизвестного продукта.
- **SSE**: при остановке API потоки закрываются сразу; заголовок `Last-Event-ID` разрешён в CORS; на запись в поток действует срок.

Вне изменения:

- поток SSE, который молчит при остановленной Kafka: сервер его не различает, страховочный перезапрос делает frontend;
- склейка частых сигналов и сигнал об истечении срока партии;
- низкие находки `backend/review.md`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `catalog`: порядок событий при одновременной смене рецептуры.
- `stock`: чтение партий продукта - страницы, фильтр по остатку, неизвестный продукт.
- `realtime-updates`: завершение потоков при остановке, переподключение из браузера, срок на запись.

## Impact

- `backend/`: `internal/catalog/service.go`, `internal/inventory` (чтение партий, обработчик), `internal/realtime`, `internal/platform/httpx` (CORS), `cmd/api`, `api/openapi.yaml` и сгенерированный `internal/api/oas`, тесты, `AGENTS.md`.
- `backend/api/openapi.yaml` меняется, затрагивает frontend: у списка партий появляются параметры `limit`, `offset`, `in_stock` и поле `total`; без параметров возвращается первая страница из 50 партий, а не все. Неизвестный продукт теперь даёт 404.
- SSE писал разработчик B.
