## ADDED Requirements

### Requirement: Пароли realm задаются снаружи
Файл realm SHALL принимать пароли тестовых пользователей и секрет сервисной учётной записи генератора из переменных окружения контейнера Keycloak. Без этих переменных SHALL действовать значения локального окружения: пароль пользователя равен логину, секрет генератора прежний.

#### Scenario: Локальный запуск без переменных
- **WHEN** локальное окружение поднимают как раньше, не задавая переменных
- **THEN** вход пользователем `approver` с паролем `approver` и получение токена генератора с прежним секретом работают

#### Scenario: Заданный пароль
- **WHEN** Keycloak запущен с переменной пароля пользователя `admin`
- **THEN** вход с заданным паролем проходит, а с паролем `admin` отклонён
